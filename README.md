**La Caja Negra al Descubierto:** 
Auditoría Algorítmica y el Impacto del Etiquetado de Datos
*Objetivo del Proyecto:* Demostrar que un modelo de Inteligencia Artificial es tan robusto como la calidad de los datos que lo alimentan, construyendo el motor matemático desde cero para auditar su comportamiento
1. **El Desafío Técnico**
2.  (El Motor)Para comprender realmente cómo toma decisiones una IA, decidí no utilizar librerías prefabricadas (como TensorFlow o PyTorch).
3.  Construí una Red Neuronal Profunda multicapa orientada a objetos utilizando estrictamente álgebra lineal pura en NumPy.
4.  Arquitectura Dinámica: Implementación de propagación hacia adelante (Forward Propagation) y retropropagación (Backpropagation) mediante derivadas calculadas a mano.
5.  Adaptabilidad: El modelo utiliza funciones de activación no lineales (Tangente Hiperbólica) para doblar el espacio matemático y clasificar topologías complejas que los modelos estadísticos tradicionales no pueden resolver.

3. **Conclusión y Valor Profesional**

 *Este experimento demuestra visualmente un principio fundamental de la Inteligencia Artificial:* 
 un algoritmo matemáticamente perfecto colapsa si la curaduría de sus datos es deficiente.Comprender la arquitectura interna de un modelo de Machine Learning me permite abordar tareas de anotación de datos y entrenamiento de IA no como un proceso mecánico, sino con una visión analítica integral. 
 Conozco exactamente cómo un falso positivo, un sesgo de selección o un error de etiquetado en la etapa de preprocesamiento se propaga a través de los gradientes matemáticos, destruyendo la precisión final del modelo en producción.
